# 舒尔特方格 · 注意力训练

单文件 HTML 实现的舒尔特方格（Schulte Grid）训练器。**零依赖、零联网**，下载 `index.html` 双击就能用；也可以直接在线打开。

## 在线玩

- GitHub Pages：启用后访问 `https://N0-1-C.github.io/schulte-grid/`
- Gitee Pages：启用后访问 `https://cqhup.gitee.io/schulte-grid/`

## 本地使用

下载 `index.html`，双击用浏览器打开。不需要安装、不需要服务器、不会发起任何网络请求。

## 玩法

网格里随机散布 1 ~ N²，按 **1 → 2 → 3 → …** 的顺序依次点击，全程计时。
训练时眼睛尽量**盯住中心点**，只靠余光搜索数字 —— 这是舒尔特方格提升注意广度的关键，而不是用眼睛扫。

## 功能

| 功能 | 说明 |
|---|---|
| 网格尺寸 | 3×3 / 4×4 / 5×5 / 6×6 / 7×7，成绩按尺寸分别记录 |
| 计时 | 毫秒级，从倒计时结束开始，到点完最后一个数字为止 |
| 失误统计 | 点错记一次失误，格子红框抖动，不计入计时惩罚 |
| 中心注视点 | 仅在训练进行中显示，可开关 |
| 音效 | Web Audio 实时合成，正确音随进度升高，点错低音提示，可开关 |
| 成绩记录 | 本地保存最佳成绩 + 最近 20 次，结果页显示近 5 次 |
| 全屏 | 减少干扰，沉浸训练 |
| 移动端 | 自适应布局，触摸操作 |

## 评级

按**每格平均耗时**评定，与网格尺寸无关（所以 7×7 和 5×5 的评级是同一把尺子）：

| 每格平均 | 评级 |
|---|---|
| ≤ 0.65 s | 神级反应 |
| ≤ 0.95 s | 优秀 |
| ≤ 1.40 s | 良好 |
| > 1.40 s | 继续练习 |

参考：5×5（25 格）达到「优秀」约需 24 秒内。

## 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 开始 / 重新开始 |

## 技术说明

- 单文件，HTML + CSS + 原生 JS，无框架、无构建步骤、无 CDN。
- 成绩与设置存在 `localStorage`（键前缀 `schulte.`），清浏览器数据即重置。
- 格子字号按实测边长动态计算（`ResizeObserver`），任意窗口尺寸下数字都保持合适大小。
- 倒计时期间数字透明，避免提前记忆位置。

## 浏览器要求

Chrome / Edge 90+、Firefox 90+、Safari 15+（需要 `aspect-ratio` 与 `pointerdown`）。
